Authentication

Create a key in the bot with /apikey new my-app or on the Developers tab of the My Files page. The key is shown once. Send it with every request:

curl {{.Host}}/api/v1/files \
  -H "Authorization: Bearer fsb_xxxxxxxx"

You can also use the X-API-Key header. Limit: 120 requests per minute per key. A key can only see and change the links of its owner.

Endpoints

GET/api/v1/meYour storage summary
GET/api/v1/files?q=&folder=&limit=List links, newest first (limit up to 500)
GET/api/v1/files/{id}One link with views, downloads, countries and devices
DELETE/api/v1/files/{id}Revoke a link (it stops working immediately)
PATCH/api/v1/files/{id}Change expiry, password, view limit, folder, name

How links are created

Links are made by the bot: send a file to the bot (from the Telegram app, or from your own code with a user client such as Telethon or Pyrogram) and it replies with a link. Your service can learn about every new link in two ways:

  • Subscribe to the link.created webhook, which is pushed to you instantly, or
  • poll GET /api/v1/files (newest first).

Then use PATCH /api/v1/files/{id} to set expiry, password, view limit, folder or name:

curl -X PATCH {{.Host}}/api/v1/files/1234 \
  -H "Authorization: Bearer fsb_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"expiry_hours": 24, "max_views": 1, "password": "s3cret", "folder": "Course"}'
FieldMeaning
nameDisplay name (1-200 characters).
folderLabel to group links (up to 40 characters, empty to clear).
expiry_hours-1 = never expires, otherwise 1-8760 hours from now.
max_views1 makes a one-time link. 0 = unlimited. Setting a limit restarts the count.
password4-100 characters. Requires the web player. Use "clear_password": true to remove it.
revokedtrue disables the link, false enables it again.

Responses look like this:

{
  "id": 1234, "name": "movie.mkv", "size": 1048576000, "mime": "video/x-matroska",
  "status": "active", "protected": true, "max_views": 1, "views": 0,
  "downloads": 0, "countries": {"IN": 2}, "devices": {"Mobile": 1, "Desktop": 1},
  "watch_url": "{{.Host}}/watch/1234?hash=abc123"
}
Links with a password do not include stream_url or download_url: visitors open watch_url and enter the password.

Webhooks

Set an HTTPS URL with /webhook https://example.com/hook (or on the Developers tab). Private and local addresses are blocked. Events:

EventWhen
link.createdA new link was made (bot or channel); the data holds the link URLs
link.viewedA new visitor opened a link (one per visitor per 10 minutes; link previews are ignored)
pingTest event from /webhook test
POST /your-endpoint
X-Fsb-Event: link.viewed
X-Fsb-Signature: sha256=3f1c...e9

{"event":"link.viewed","time":1767225600,"data":{"id":1234,"name":"movie.mkv","device":"Mobile","country":"IN","views":3}}

Verify the signature

The signature is the HMAC-SHA256 of the raw request body, using your signing secret (shown by /webhook).

# Python
import hmac, hashlib
def valid(body: bytes, header: str, secret: str) -> bool:
    mac = hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest("sha256=" + mac, header)

// Node.js
const crypto = require("crypto");
const ok = (body, header, secret) =>
  header === "sha256=" + crypto.createHmac("sha256", secret).update(body).digest("hex");

Reply with any 2xx status. A failed delivery is retried once after 2 seconds.

country is filled only when your host or CDN sends a country header (for example Cloudflare's CF-IPCountry). Otherwise it is ??.

Telegram features

Mini App

Set HOST to your public https URL. The bot then shows an Open App button and a menu button that open {{.Host}}/app inside Telegram, where users are signed in automatically.

Inline mode

Enable it once with @BotFather: /setinline. Then type @yourbot (optionally followed by part of a file name) in any chat to share one of your links.

Channel mode

Add the bot as an admin of your channel (it needs permission to edit messages) and post /watchbuttons there. The bot owner approves the request, and every new media post in that channel gets Watch and Download buttons. Post /watchbuttons off to stop.
